Pharmacy Dashboard 

Introduction

This project is created using Microsoft Excel to analyze and visualize pharmacy sales and inventory data. The dashboard provides a simple and interactive way to understand sales performance, product performance, inventory levels, and other important business information.

Objective

The main objective of this project is to create a simple and interactive pharmacy dashboard using Microsoft Excel. The dashboard helps users monitor pharmacy sales, inventory levels, product performance, and overall business performance.

Dataset Information

The dataset contains sample pharmacy sales and inventory data. The data was organized and formatted in Microsoft Excel for analysis and dashboard creation.

Columns Used

- Product Name
- Category
- Sales
- Quantity
- Date
- Stock Level
- Price
- Profit

Dashboard Features

- Sales Trend Analysis
- Top-Selling Products
- Inventory Status
- Category Analysis
- Profit Analysis
- Pivot Tables
- Pivot Charts
- Excel Charts
- Filters and Slicers

Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Charts
- Slicers and Filters
- Data Cleaning and Formatting

How to Use

1. Open the "Pharmacy Dashboard 1.0.xlsx" file using Microsoft Excel.
2. Open the Dashboard worksheet.
3. Use the available filters or slicers to select specific data.
4. Review the charts, tables, and key performance indicators.
5. Update the source data when required.
6. Refresh the Pivot Tables and Pivot Charts after updating the data.

Conclusion

The Pharmacy Dashboard 1.0 project provides a simple and effective way to analyze pharmacy sales and inventory data using Microsoft Excel. The dashboard converts raw data into meaningful visual information through charts, tables, Pivot Tables, and interactive filters.

This project demonstrates the practical use of Microsoft Excel for data analysis, visualization, and dashboard development.
